Meeting Recorder — Extension Settings

Configure where to send captured OWA + Teams content.

From Meeting Recorder → Settings → Chrome Extension. The port changes each launch; if captures stop working after a restart, refresh this value.

From the same screen. New token on every recorder launch.

How it works

1. You stay signed in to Outlook + Teams in this Chrome (your normal browsing session).

2. Click the extension's toolbar icon → Capture & Send.

3. The extension opens outlook.office.com/calendar/view/day + teams.microsoft.com/.../activity in tabs, waits ~10 seconds for each to render fully, reads the [role="main"] inner text, closes them.

4. Content is POSTed to your local Meeting Recorder backend; the LLM parses it into a daily briefing exactly like the existing Import briefing flow does.

5. Because the scrape runs in YOUR Chrome (no Playwright, no automation flags), Microsoft's bot detection doesn't fire and your real session cookies work.
